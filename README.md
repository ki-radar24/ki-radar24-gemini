# KI-Radar24 für Gemini CLI

Finde KI-Tools, KI-Unternehmen und KI-Freelancer aus dem deutschen Verzeichnis [KI-Radar24](https://ki-radar24.de) direkt in Gemini CLI.

## Installation

```bash
gemini extensions install https://github.com/ki-radar24/ki-radar24-gemini
```

Danach einfach fragen, zum Beispiel:

- „Welche KI-Tools gibt es für Buchhaltung?“
- „Finde eine KI-Agentur in München.“
- „Vergleiche ChatGPT, Claude und Gemini.“
- „Ich suche einen KI-Freelancer für Chatbots unter 80 € pro Stunde.“

## Was die Erweiterung kann

| Werkzeug | Zweck |
|---|---|
| `ki_tools_suchen` | KI-Tools nach Aufgabe, Kategorie oder Preis |
| `ki_unternehmen_suchen` | KI-Unternehmen und Agenturen, auch nach Ort |
| `freelancer_finden` | KI-Freelancer nach Fähigkeit, Ort und Stundensatz |
| `vergleichen` | Einträge nebeneinander vergleichen |
| `search`, `fetch` | Allgemeine Suche und Details |

Alle Werkzeuge sind nur lesend und brauchen keine Anmeldung. Server: `https://ki-radar24.de/mcp`
